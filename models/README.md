# Model Drop Zone

Drop licensed GLB assets here. The app currently uses procedural PBR proxies and lists expected production slots in the Photoreal Asset Pipeline panel.

Suggested structure:

```text
models/
  anatomy/
    patient-abdomen.glb
    skin-fat-fascia-liver-gallbladder.glb
  tools/
    laparoscopy-toolkit.glb
  ot/
    surgical-theater-equipment.glb
```

Keep marketplace licenses outside the public app bundle unless redistribution is allowed.
